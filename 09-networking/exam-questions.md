# Exam Questions - Networking

## Question 1

You need to expose HTTP traffic globally. Which load balancer should you use?

A) Network Load Balancer  
B) HTTP(S) Load Balancer  
C) Internal Load Balancer  
D) TCP Proxy Load Balancer

**Правильна відповідь:** B

**Пояснення:** HTTP(S) Load Balancer - глобальний Layer 7 балансувальник для HTTP/HTTPS трафіку.
