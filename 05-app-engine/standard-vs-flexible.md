# Standard vs Flexible

## Standard Environment

- Швидкий запуск (мілісекунди)
- Автоматичне масштабування до 0
- Обмежені runtimes
- Безкоштовний tier

## Flexible Environment

- Повільніший запуск (хвилини)
- Мінімум 1 екземпляр
- Docker контейнери
- Більше контролю

| Feature      | Standard         | Flexible     |
|--------------|------------------|--------------|
| Startup      | Milliseconds     | Minutes      |
| Scale to 0   | Yes              | No           |
| Pricing      | Instance hours   | vCPU/memory  |
| SSH          | No               | Yes          |
