# Exam Questions - App Engine

## Question 1

You need to deploy a Python web app that scales to zero when not in use. Which should you use?

A) App Engine Standard  
B) App Engine Flexible  
C) Compute Engine  
D) GKE

**Правильна відповідь:** A

**Пояснення:** Тільки App Engine Standard може масштабуватися до 0 екземплярів.

**Чому інші варіанти неправильні:**

- B: Flexible потребує мінімум 1 екземпляр
- C/D: Не масштабуються до 0
