# Exam Questions - Databases

## Question 1

You need a globally distributed relational database with strong consistency. Which should you use?

A) Cloud SQL  
B) Cloud Spanner  
C) Firestore  
D) Bigtable

**Правильна відповідь:** B

**Пояснення:** Cloud Spanner - єдина глобально розподілена реляційна БД з сильною консистентністю.
