# Exam Questions - Deployment & Management

## Question 1

You need to automate infrastructure deployment using templates. Which tool should you use?

A) Cloud SDK  
B) Deployment Manager  
C) Cloud Build  
D) Terraform

**Правильна відповідь:** B

**Пояснення:** Deployment Manager - нативний GCP інструмент для Infrastructure as Code з YAML templates.
