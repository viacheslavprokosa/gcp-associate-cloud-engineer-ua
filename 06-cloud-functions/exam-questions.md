# Exam Questions - Cloud Functions

## Question 1

You need to process files automatically when uploaded to Cloud Storage. Which trigger should you use?

A) HTTP trigger  
B) Cloud Storage trigger  
C) Pub/Sub trigger  
D) Cloud Scheduler

**Правильна відповідь:** B

**Пояснення:** Cloud Storage trigger автоматично запускає функцію при upload файлів.

**Чому інші варіанти неправильні:**

- A: HTTP для manual invocation
- C: Pub/Sub для messaging
- D: Scheduler для cron jobs
