# Основні сервіси GCP

## Compute (Обчислення)

- **Compute Engine** - Віртуальні машини (IaaS)
- **Google Kubernetes Engine (GKE)** - Керований Kubernetes
- **App Engine** - PaaS для додатків
- **Cloud Functions** - Serverless функції
- **Cloud Run** - Контейнери без управління інфраструктурою

## Storage (Сховища)

- **Cloud Storage** - Об'єктне сховище
- **Persistent Disk** - Блокове сховище для VM
- **Filestore** - Файлове сховище (NFS)

## Databases (Бази даних)

- **Cloud SQL** - Керовані реляційні БД (MySQL, PostgreSQL, SQL Server)
- **Cloud Spanner** - Глобально розподілена реляційна БД
- **Firestore** - NoSQL документна БД
- **Bigtable** - NoSQL wide-column БД
- **Memorystore** - Керований Redis/Memcached

## Networking (Мережі)

- **VPC (Virtual Private Cloud)** - Віртуальна приватна мережа
- **Cloud Load Balancing** - Балансування навантаження
- **Cloud CDN** - Content Delivery Network
- **Cloud DNS** - Керований DNS
- **Cloud VPN** - VPN з'єднання
- **Cloud Interconnect** - Виділене з'єднання

## Management Tools (Інструменти управління)

- **Cloud Console** - Веб-інтерфейс
- **Cloud SDK (gcloud)** - Командний рядок
- **Cloud Shell** - Браузерний термінал
- **Cloud Deployment Manager** - Infrastructure as Code
- **Cloud APIs** - REST API для всіх сервісів

## Monitoring & Operations

- **Cloud Monitoring** - Моніторинг ресурсів
- **Cloud Logging** - Централізовані логи
- **Cloud Trace** - Трейсинг запитів
- **Cloud Debugger** - Дебаггінг в production
- **Error Reporting** - Звіти про помилки
