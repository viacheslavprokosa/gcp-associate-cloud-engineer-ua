# Exam Questions - IAM & Security

## Question 1

You need to grant a user read-only access to all resources in a project. Which role should you use?

A) roles/owner  
B) roles/editor  
C) roles/viewer  
D) roles/compute.viewer

**Правильна відповідь:** C

**Пояснення:** roles/viewer надає read-only доступ до всіх ресурсів проекту.
