# Cloud Storage

## Основи

- Об'єктне сховище
- Необмежена ємність
- Глобальна доступність

## Команди

```bash
# Створити bucket
gsutil mb gs://my-bucket

# Завантажити файл
gsutil cp file.txt gs://my-bucket/

# Список файлів
gsutil ls gs://my-bucket/
```
