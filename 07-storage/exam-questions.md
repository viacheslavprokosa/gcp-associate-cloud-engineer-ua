# Exam Questions - Storage

## Question 1

You need to store archival data accessed less than once per year. Which storage class should you use?

A) Standard  
B) Nearline  
C) Coldline  
D) Archive

**Правильна відповідь:** D

**Пояснення:** Archive клас найдешевший для даних з доступом < 1 раз/рік.
