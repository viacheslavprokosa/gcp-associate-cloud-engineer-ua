# Mixed Topics

## Question 1

Which storage option provides the lowest latency for VM workloads?

A) Cloud Storage  
B) Persistent Disk  
C) Local SSD  
D) Filestore

**Правильна відповідь:** C

**Пояснення:** Local SSD надає найнижчу latency, оскільки фізично прикріплений до VM host.

## Question 2

You need to grant temporary access to a Cloud Storage bucket. What should you use?

A) IAM policy  
B) Signed URL  
C) ACL  
D) Bucket policy

**Правильна відповідь:** B

**Пояснення:** Signed URLs надають тимчасовий доступ з expiration time без зміни IAM policies.
